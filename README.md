# Soccer Master 27 (SM27)

Первая рабочая основа футбольного менеджера: FastAPI, Neon PostgreSQL 17, адаптивный интерфейс и симулятор тура. Код написан под существующую схему Neon Soccer Master 27 — Supabase не используется.

## Что уже работает в этой версии

- Регистрация и вход менеджера с PBKDF2-хешированием пароля и HttpOnly-сессией.
- Выбор клуба из каталога SM27 и создание отдельного сохранения.
- Игровые копии клубов и составов, тактика, турнирная таблица и календарь.
- Генерация double round-robin календаря для выбранной лиги.
- Симуляция всех матчей тура, события голов, статистика и обновление очков.
- Адаптивный интерфейс под телефон и компьютер.
- Один небольшой пул БД (максимум 4 соединения), без постоянно работающего фонового симулятора.

Это MVP, не финальная игра: трансферный рынок, молодёжная академия, травмы/дисквалификации, полноценный live match engine, кубки и еврокубки будут следующими этапами.

## Источники данных (проверено на 22.11.2026)

### Клубы и составы

OpenFootballBase-Data, последний доступный релиз на дату среза — **Data 1.24.0 от 21.11.2026**: 44 970 карточек клубов, 85 099 игроков, 327 375 записей состава по сезонам и 152 соревнования (агрегированные числа проекта опубликованы 14.11.2026; релиз данных обновлён 21.11.2026). Импортёр выбирает до 750 клубов, участвующих в открытом сезоне 2026/27, а не случайные исторические клубы. Неполнота текущих составов учитывается: для клуба без проверенного состава интерфейс отмечает, что игровой состав сформирован SM27.

Источник: https://github.com/florentfougeres/OpenFootballBase-Data/releases/tag/data-1.24.0

Лицензия данных OpenFootballBase: Wikipedia CC BY-SA 4.0 и Wikidata CC0. Код исходного data pipeline — MIT. Атрибуция и ссылка на источник сохраняются в `raw_data` и таблице `data_import_runs`.

### Рыночные стоимости

Опциональное сопоставление с датасетом Transfermarkt Player Market Values (November 2026), прочитанным с публичных профилей 19.11.2026 и выпущенным под CC BY 4.0. В нём 2 623 игрока из пяти топ-лиг; у каждой стоимости хранится `market_value_date`. Значения не смешиваются с игровым рейтингом и не выдаются за сумму реального трансфера.

Источник: https://huggingface.co/datasets/minmaxxxer/transfermarkt-player-market-values-2026-11

### Важные ограничения

- Текущая полнота 2026/27 неодинакова между странами и лигами. Импортёр берёт только участников открытого сезона и сохраняет флаг наличия подтверждённого состава.
- Логотипы Wikimedia/Wikipedia используются только при наличии свободной лицензии или ссылки на Wikimedia Commons; эмблемы с `non-free` / `fair use` не вставляются.
- Игровые `overall` и `potential` — алгоритмическая оценка SM27, не официальные атрибуты игрока и не данные Transfermarkt.
- Игроки `Игрок академии XX` — вымышленные заглушки для игрового прохождения, а не реальные футболисты.

## Загрузка в GitHub через github.dev

1. Распакуй ZIP-пакет локально.
2. Открой https://github.dev/idzelenski/soccer-master-27.
3. Перетащи содержимое папки `sm27_project` в файловый проводник github.dev (сохраняя папки `app`, `scripts`, `sql`, `tests`, `.github`).
4. В Source Control проверь изменения, напиши commit message `Initialize Soccer Master 27 MVP` и нажми **Commit & Push**.
5. После push Render сможет прочитать `render.yaml` и автоматически собирать ветку `main`.

## Подключение Render к Neon

1. В Render выбери **New → Blueprint** и укажи этот репозиторий. Blueprint создаёт Web Service `soccer-master-27` в Frankfurt на Free plan.
2. В Environment добавь `DATABASE_URL` — pooled connection string из Neon (host должен содержать `-pooler`, SSL `sslmode=require`). Не вставляй строку подключения в GitHub или этот README.
3. После первого успешного deploy открой Shell сервиса и один раз выполни:

   ```bash
   python -m scripts.import_catalog
   ```

   Скрипт сам находит последний GitHub release OpenFootballBase, скачивает архив, сверяет SHA-256, извлекает только нужные Parquet-файлы и импортирует текущий сезон в Neon.

4. Открой адрес Render-сервиса. Health endpoint: `/api/health`.

При повторном запуске импортёр обновляет записи по стабильным ID, а не создаёт дубликаты.

## Локальный запуск

Требуется Python 3.12+.

```bash
python -m venv .venv
source .venv/bin/activate           # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env                # Windows: copy .env.example .env
# Заполни DATABASE_URL в .env
uvicorn app.main:app --reload
```

Импорт каталога выполняется отдельно командой `python -m scripts.import_catalog`.

## Безопасность и бесплатные лимиты

- Секреты живут только в Render Environment / локальном `.env`.
- Neon connection pool ограничен четырьмя соединениями; авто-suspend Neon остаётся включённым.
- Матчи симулируются только по нажатию менеджера, никаких постоянных фоновых воркеров.
- Free Render может засыпать. Игровое время не идёт автономно во время сна сервиса.
